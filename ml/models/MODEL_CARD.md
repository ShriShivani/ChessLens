# Model card: SquareNet (synthetic baseline)

**Status: research baseline. Trained on synthetic data only. Not validated on any real board.**

| | |
|---|---|
| Model | `SquareNet`, tiny 4-block CNN from scratch, two heads (occupancy/colour 3 classes, piece type 6 classes) |
| Input | 96x96 RGB crop of one square (128 px with 14 px context, resized), float 0..1, normalised inside the model |
| Output | Occupancy logits (3) and type logits (6); joined into 13 class probabilities; temperatures stored in the `.json` next to the ONNX file |
| Training data | 12 synthetic games x 8 boards (96 boards, 6,144 crops, 4 colour/lighting "sessions"), crops from `ml/scripts/render_synthetic.py`. Train 6 games (2 sessions, 3,072 crops), validation 3 games, test 3 games (an unseen session) |
| Training | 12 epochs max, AdamW, label smoothing 0.05, class-weighted loss, early stopping on validation loss, seed 0, git commit `1cf5f70` (repository state before this work was committed) |
| Intended use | Verifier and recovery aid beside the move tracker (`edge/verify.py`); never the sole source of the position |

## Results (synthetic test split, 24 boards, 1,536 crops, unseen session)

Produced by `python -m ml.evaluate --run ml/runs/synthetic_tiny --split test`.

| Metric | Value |
|---|---|
| Occupancy/colour accuracy | 100.0% |
| Piece-type accuracy on occupied squares | 83.7% |
| 13-class square accuracy | 92.6% |
| Full-board exact match | 0 of 24 boards (0%) |
| Border squares / interior squares | 89.1% / 95.3% |
| Occupancy calibration error (ECE) | 0.000 after temperature scaling (0.076 before) |
| Weakest classes by recall | black knight 2%, white knight 6%, white queen 62%, white bishop 67% |

Test split is small. These numbers are for pipeline checking only.

## Known weaknesses

- Knights are almost never recognised, bishops and queens often confused. On the synthetic data
  that is because the knight mark is small; on real boards the same pairs are expected to be the
  hardest from above (see ML_PLAN.md).
- The synthetic piece look is invented. Real pieces, shadows, glare and hands are untested.
- Full-board exact match is 0%: even a few wrong piece types spoil every board. Use occupancy for
  verification, not piece types for decisions.
- Latency on the development laptop was about 62 ms per 64-crop board (CPU, onnxruntime).

## Data and licences

All training images were generated by code in this repository; no third-party pieces, images or
datasets were used. Before using public datasets (ChessReD, Roboflow) or pretrained weights for a
commercial product, check their licences.
